## 🌟 Ключевые функции (Версия 1.0.0)

### 🖥️ Автоматический поиск на ПК
* **Полная автоматизация**: Автоматически выполняет дневную норму поисков Bing на ПК (По умолчанию: 30 поисков ~90 баллов Rewards).
* **Умное управление вкладками**: Открывает поисковые вкладки в фоновом режиме и закрывает их по завершении.
* **Калькулятор баллов в реальном времени**: Отображает заработанные баллы прямо в интерфейсе Popup (+3 балла за поиск).

### 🛡️ Bing Anti-Bot Humanizer Pro
* **Реалистичная симуляция поведения человека**:
  * Многоэтапная плавная прокрутка.
  * Естественное движение мыши и наведение курсора на результаты или вкладки Bing (Новости, Картинки, Карты).
  * Случайное выделение текста.
  * Настраиваемые паузы задержки (Min/Max Delay) для обхода обнаружения ботов.
