# 🤝 Contributing to Microsoft Reward Automation

First off, thank you for considering contributing to **Microsoft Reward Automation**! It's open-source projects like this that make the community such an amazing place to learn, inspire, and create.

---

## 🛠️ Ways You Can Contribute

1. **🌐 Add or Improve Translations**:
   - We support 12+ global languages! Check our [TRANSLATIONS.md](TRANSLATIONS.md) guide to easily add your native language or fix typos.

2. **🐛 Bug Reports**:
   - Found a bug or anti-bot edge case? Open an issue on GitHub describing the steps to reproduce, browser version, and console logs.

3. **✨ Feature Requests & Keyword Banks**:
   - Have ideas for new humanizer anti-bot patterns or procedural keyword categories? Open an issue or submit a PR!

---

## ⚡ Development Workflow

1. **Fork the Repository**: Click "Fork" at the top right of [github.com/stevenquan4567/microsoft-reward-automation](https://github.com/stevenquan4567/microsoft-reward-automation).
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/microsoft-reward-automation.git
   cd microsoft-reward-automation
   ```
3. **Load Extension in Edge / Chrome**:
   - Go to `edge://extensions` or `chrome://extensions`
   - Enable **Developer Mode** (top right toggle)
   - Click **Load Unpacked** and select the repository folder.
4. **Test your changes**:
   - Run verification script:
     ```bash
     node scratch/verify_extension.js
     ```
5. **Commit and Submit PR**:
   - Write clear commit messages.
   - Push to your fork and submit a Pull Request to `main`.

---
